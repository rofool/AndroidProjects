# Практическая работа №4

Приложение на Jetpack Compose. Из списка можно открыть карточку приложения.
Внизу карточки находится «Витрина»: три страницы по три приложения.
Нажатие на приложение в витрине возвращает к списку.

Карточка взята из [примера преподавателя](https://github.com/maltsevmicyou/VkEducation/tree/b4c673ba2c65fdab3277c144aae300947e43dcb6).
Список и витрина используют общий компонент. Навигация сделана через
NavHost, composable и navController. Данные и иконки учебные.

В предыдущих ветках проекта списка приложений не было, поэтому для него
использован элемент из примера преподавателя.

Для запуска открыть проект в Android Studio и запустить app.
Сборка и тесты проверены на эмуляторе Pixel 8.
