# Практическая работа №5

В каталог приложений добавлен MVVM на Jetpack ViewModel.
Данные хранятся в ViewModel и не загружаются заново при повороте экрана.
По нажатию на тулбар появляется Snackbar. После поворота он не повторяется.

Основа — каталог из ветки hw4-compose-app-list.
Для запуска открыть проект в Android Studio и запустить app.
