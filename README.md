# Витрина приложений — практическая работа №4

Android-приложение на Kotlin и Jetpack Compose.

## Запуск

Открыть проект в Android Studio, дождаться Gradle Sync и запустить `app`.
Требуется Android SDK 37, устройство или эмулятор с Android 7.0 (API 24) и выше.
Gradle Wrapper и настройки JVM включены в репозиторий; путь к Android SDK
Android Studio задаёт в локальном `local.properties`.

## Поведение

1. Начальный экран — список из девяти приложений.
2. Нажатие на приложение открывает его карточку.
3. В самом низу карточки, после блока разработчика, находится «Витрина».
4. Горизонтальный свайп перелистывает ровно три страницы по три приложения.
5. Нажатие на любой элемент витрины возвращает к списку приложений.
6. Кнопка «Назад» и системная навигация возвращают к списку.

Список и витрина используют один `AppListItem`. Навигация реализована через
`rememberNavController`, `NavHost` и `composable`. Данные девяти приложений
заданы локально; состояние страницы сохраняется при пересоздании Activity.

## Готовый UI преподавателя

Карточка перенесена из [maltsevmicyou/VkEducation](https://github.com/maltsevmicyou/VkEducation/tree/b4c673ba2c65fdab3277c144aae300947e43dcb6):
`AppDetailsContent`, `AppDetailsHeader`, `Toolbar`, `InstallButton`,
`AppDescription`, `Developer`, `ScreenshotsList`, `SimilarApps`, модели и тема.
Общий элемент списка основан на `SimilarAppItem` из того же репозитория.
Точная карта адаптации — [SHOWCASE_NOTES.md](SHOWCASE_NOTES.md).

Иконки, возраст и размер — локальные демонстрационные данные. Реальные
скриншоты не заданы. Кнопки установки, разработчика и отправки показывают
сообщение «В процессе разработки», как в практическом примере.

## Проверка

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

Для второй команды нужен запущенный эмулятор или подключённое устройство.
Тесты проверяют три страницы, перелистывание назад, отсутствие четвёртой
страницы, восстановление после пересоздания Activity и переходы по всем
девяти элементам витрины.
