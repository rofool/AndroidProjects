# Практическая работа №6

Каталог приложений разделён на три слоя:

- data — локальные данные в DTO, Mapper и реализация Repository;
- domain — модели и интерфейс Repository;
- presentation — экран на Compose, ViewModel и состояние экрана.

Данные проходят через DTO → Mapper → Domain model → ViewModel → экран.
По нажатию на тулбар появляется Snackbar без повторного показа при повороте.
ViewModel сохраняет данные при пересоздании экрана.
При ошибке доступна повторная загрузка. Иконки и список работают без интернета.

Основа — каталог из ветки hw4-compose-app-list.
Для запуска открыть проект в Android Studio и запустить app.
