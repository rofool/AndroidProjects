# Практическая работа №8

Каталог загружается с сервера через Retrofit: `GET http://185.103.109.134/catalog`.
На экране показаны данные и иконки сервера. Есть загрузка, ошибка и кнопка повторного запроса.
Сохранены слои data/domain/presentation, DTO и мапперы.

Запрос подробностей по ID реализован отдельно и к экрану не подключён, как в задании.
Указанный в условии `/{id}` сейчас отвечает 404. Только при таком ответе выполняется
запрос `/catalog/{id}` — этот адрес работает и используется в примере преподавателя.
